# Fresh Pick QA 체크리스트

## 빠른 화면 검증

1. 로컬 서버를 실행한다.
2. `http://127.0.0.1:4173/`을 연다.
3. 상품 종류를 하나 선택한다.
4. `샘플 분석`을 누른다.
5. 후보 카드 3개가 생성되는지 확인한다.
6. 결과 영역이 열리는지 확인한다.
7. BEST PICK 카드, 가성비 추천, 후보별 비교 패널, 순위 리스트가 함께 보이는지 확인한다.
8. 다른 상품 종류로 바꾼 뒤 다시 `샘플 분석`을 눌러 문구와 지표가 해당 카테고리에 맞게 바뀌는지 확인한다.

## 카테고리별 확인 포인트

- 소고기 구이용: 지방량, 지방 분포, 색 안정감 문구가 자연스러운지 확인한다.
- 잎채소: 생기, 변색, 시듦 문구가 고기 용어 없이 표시되는지 확인한다.
- 토마토: 색 균일도, 표면 상처, 무름 의심 문구가 보이는지 확인한다.
- 오이: 초록색 선명도, 표면 탄탄함, 주름/상처 문구가 보이는지 확인한다.
- 사과: 색 균일도, 멍/상처, 눌림 신호 문구가 보이는지 확인한다.

## 비용 안전 확인

- `샘플 분석`은 OpenAI API를 호출하지 않는다.
- 실제 API 호출은 `분석하기` 또는 `라벨 읽기`를 눌렀을 때만 발생한다.
- API key는 브라우저에 노출되지 않는다.

## 정적 테스트

```powershell
node .\prototype\smoke-test.mjs
```

확인 항목:

- HTML, 프론트 설정, 백엔드 프롬프트에 모든 상품 모드가 존재한다.
- 야채/과일 모드에 고기 전용 표현이 섞이지 않는다.
- 공통 분석 필드가 프론트와 백엔드 모두에 존재한다.
- 샘플 분석 진입점이 유지된다.
